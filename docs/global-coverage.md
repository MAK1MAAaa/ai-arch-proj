## 功能与真实浏览器

Windows Chrome、本地FastAPI、1440×1100及390×844视口，浏览器阻断全部非本地网络。

1. 1534条全库目录、159个国家／地区、1033／1033来源分母正常加载；全库点使用Canvas，没有为每条创建可Tab的DOM标记。
2. 按莫桑比克浏览，无查询即可选择遗址、读取官方中文／英文原文及未核验年代；不会附虚构分数或跳转年份。
3. 无查询分享链接独立恢复遗址，不要求模型就绪或出现在检索Top50内。
4. 成功检索采用MZ条件后，目录切到CN，原查询、排名与`country=MZ`保留，`browse_country=CN`独立保存；导出保留原排名并附完整独立`selected_site`，无伪分数。
5. 模拟目录503后保留成功点层和范围，分享仍保存成功的CN；点层即时关闭与重试后JP成功范围均正确。
6. 分页只请求下一页，不重新获取全量点；CN与非洲交集为空时保留之前检索结果。
7. 真实本地E5对新中文问题编码，国别CN过滤后检索到长城`whc:438`。
8. 390px布局无横向溢出；目录按钮支持键盘，选中标记Space重开、Escape返回标记焦点。

另有独立Chrome恢复专项：缺模型时保留原查询URL、恢复国别、拒绝空国别、用户目录操作优先于晚到初始化，以及无查询非法国别保持URL并阻止搜索，均通过。目录的desired与committed状态分别保存：下一次查询可使用用户当前输入，分享和导出使用最后成功范围，历史年份继续使用最后成功地图。
