# 固定地图范围浏览验收

验收日期：2026-11-04。语料仍为`global-v6`的1689条，来源定位侧车为`world-locations-v1`，没有修改原文、代表点、历史阶段、检索文档或E5索引。本批改进地区浏览，不声称新增全球遗址覆盖或已证明检索相关性；人工相关性指标仍为`null`。

## 行为与边界

- “按当前地图范围浏览”显式捕获主图矩形；平移、缩放不自动重筛，更新和清除须主动操作。与目录国家／地区、来源分区取交集，API另支持类型交集。
- 遗产原代表点或任一来源点在闭区间内即可入选一次；不以组成点数增加目录计数，不用坐标推断国家或历史主权。全库点层只绘范围内点，详情与导出保留完整原序列和重复记录。
- 支持跨日期变更线、西东±180°别名和跨整周的地图显示副本。资料坐标保持原值；极区源点可参与WGS84接口匹配，主图继续遵循Mercator显示限制，独立南极示意不被主图范围筛选。
- 空、重复、非有限值、越界和零面积范围拒绝，不补零或静默放宽。范围启用时无可核点资料排除，清除条件后恢复。
- 目录响应必须匹配请求范围、语料版本、来源点版本与匹配方式；失败、取消或过期响应保留成功范围、目录和点层。分享及导出使用成功快照。
- 无效`browse_bbox`链接暂停目录加载并持续报错，刷新不解除；有效查询、年份及选择可独立恢复。只有显式清除或重新捕获才能解除，期间禁用研究视图复制与导出并保留原地址，避免手动改写查询后仍复制原错误链接。
- 来源侧车不可用时明确按原代表点匹配，声明`representative-only`和空定位版本；来源多点缺失不扩大到全库。

## 外网阻断的Chrome交互

浏览器阻断所有非本地请求，使用本地自然地理轮廓、历史库与真实1689条资料，七组检查通过：

1. 在Manaus捕获范围，仅一个遗产、一个范围内来源点（三个相邻世界绘图副本）；Enter打开目录详情保留镜头，成功检索排名及1930年保留，导出仍含两条原始源点。
2. 平移不重筛；更新范围故意返回HTTP503后，目录、点层、分享和导出仍保存原成功范围。
3. 跨日界线链接恢复成功，原始经纬度不改写，2024年与检索快照独立保留。
4. 空范围、180°至−180°零宽、越界、重复参数均持续报错，刷新不发全库目录请求；有效查询仍恢复。手工改查询检索后，复制与导出仍禁用、原URL保留，入口保护也提示先解决范围。主动清除后不重新检索即可复制或导出，保留改写后的查询和排名。
5. 没有查询的错误范围链接可重新捕获并恢复目录，不提交隐式搜索或产生检索导出。
6. 模拟来源侧车未准备，目录与点层一致按原代表点匹配；Manaus不会凭已缺失来源点伪装命中，导出声明降级方式。
7. 390px窄屏控件无横向溢出；键盘聚焦及Enter清除成功，清除按钮禁用前焦点转入可读状态说明。

QA脚本、HTTP记录、导出快照、截图及完整独立报告保存在忽略目录`.archsearch/qa/bbox-browser/`、`.archsearch/qa/map-bounds/`及`.archsearch/qa/global-explore/bounds-independent/`。截图已逐一查看；这些本机运行产物不作为应用数据分发。

## 复现

正常准备并启动服务后，将地图移至目标地区，依次测试捕获、移动、更新、清除。可直接打开`/?browse_bbox=-60.05,-3.16,-60,-3.10`验证来源组成点，或`/?browse_bbox=170,-25,-170,25`验证跨日期变更线。查询链接加`q=port&mode=bm25&limit=10`后，范围仅影响目录；成功结果可导出版本2快照检查`browse.bbox/spatial_match_mode/spatial_version`与原始`request`。

固定来源只决定资料可追溯性，不代表覆盖已经完整。未核验断代、无可用公开坐标、未覆盖地区及人工相关性标注仍需继续完善。
