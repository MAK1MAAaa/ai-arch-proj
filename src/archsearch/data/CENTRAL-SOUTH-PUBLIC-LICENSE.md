# 厄瓜多尔、玻利维亚、巴西及圭亚那公共文化点位

本批加入厄瓜多尔 2 处、玻利维亚 3 处、巴西 3 处和圭亚那 3 处地点。访客范围依据市级遗址管理、国家文化遗产机构、议会或博物馆的公开资料。部分场所采用预约、指定展区或保育期间限定参观。新增点位的历史阶段保留未知状态。[基多市博物馆系统](https://museosquito.gob.ec/espacios/) · [玻利维亚国家民族志及民俗博物馆](https://www.musef.gob.bo/) · [巴西国家历史与艺术遗产研究所](https://www.gov.br/iphan/pt-br) · [圭亚那国家信托](https://ntg.gov.gy/)
