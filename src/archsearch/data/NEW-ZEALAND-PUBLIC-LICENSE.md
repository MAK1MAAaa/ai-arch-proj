# 新西兰公共文化点位

本批核验新西兰 25 处公开文化地点。保留管理方的逐处访客链接和开放条件。灯塔的到访证据为公共户外位置，Lyttelton 标记代表复建报时塔及原址周边。Kerikeri 的记录使用 Kemp House 自身的代表点。Mataatua Wharenui 的接待与礼仪由 Ngāti Awa 主办方安排。[Heritage New Zealand 公共名录](https://www.visitheritage.co.nz/visit) · [新西兰自然保护部文化地点名录](https://www.doc.govt.nz/parks-and-recreation/places-to-go/icon-heritage-sites/)

坐标采用逐一核对地点身份的 Wikidata [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing) 声明。冻结记录保留版本、P625 声明 ID、原始精度和快照哈希。访问依据来自主管方公开页面，网页原文和影像保留各自权利。新增点位采用断代未确定状态。
