# 莫桑比克、安哥拉公共文化点位

本批收录莫桑比克 3 处和安哥拉 5 处。马普托堡按原址重建后的公开范围收录，马普托铁屋保留迁址说明。卢安达圣米格尔堡仅采用博物馆指定区域。卢安达铁宫依主管方公布的活动开放，栋多博物馆按对外展区收录。历史阶段保留未知状态。[马普托堡管理方](https://uem.mz/fortaleza-de-maputo/) · [安哥拉文化和创意产业机构活动页](https://anicc.gov.ao/web/eventos) · [北隆达省政府](https://lundanorte.gov.ao/web/mensagem-titular)

马普托中央铁路站使用 **GeoNames** 具名铁路站 [RDF 原始坐标](https://sws.geonames.org/9254055/about.rdf)，按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 分发。其余 7 处采用 Wikidata [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing) 原始 WGS84 声明，冻结文件保留许可、原始坐标证据与公开范围。
