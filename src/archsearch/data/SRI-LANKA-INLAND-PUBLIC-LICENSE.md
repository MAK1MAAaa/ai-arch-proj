# 斯里兰卡内陆公共考古点位

本批收录德迪伽马 Soothighara 古佛塔及马利伽维拉站立佛像。德迪伽马代表点取照片资料标注的古佛塔所在位置，参观范围为省级旅游部门公布的室外原址。马利伽维拉采用具名站立佛像遗存的代表点，按照议会记录中主管部长公布的开放范围核验。断代阶段保留未知状态。[德迪伽马省级旅游说明](https://tourism.sg.gov.lk/dedigama-kotawehera/) · [斯里兰卡议会开放通告](https://www.parliament.lk/en/home/parliament-news/view/5566)
