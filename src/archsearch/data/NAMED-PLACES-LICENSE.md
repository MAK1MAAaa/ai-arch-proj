# 专名地点补充资料：来源与权利

版本 `named-places-v1`，2026-11-05 冻结。此批向原3897项资料追加莎士比亚墓，用项目ID `auth:gb-shakespeare:grave` 表示墓这一对象；不将教堂整体的 NHLE 1187824 或 Wikidata Q472082 冒充墓的独立官方编号。资料不是全球完备清单。

文化身份和室内位置依据[圣三一教堂官网](https://www.stratford-upon-avon.org/the-chancel)。1616年4月25日埋葬事件依据莎士比亚出生地信托所藏教区登记 DR243/1、fol.46r，见 [Shakespeare Documented 档案说明](https://shakespearedocumented.folger.edu/resource/document/parish-register-entry-recording-william-shakespeares-burial)。默认阶段为埋葬事件，未推断教堂建造年代、遗骨鉴定或连续生命周期。代理对照来源的复核不等于专家鉴定或人工相关性标注。

教堂网页和档案说明保留各自权利；未发现通用开放正文许可的部分仅保留事实元数据、链接和短摘录。每个来源的不同摘录合计不超过25个英文词。档案页的图像条款不被扩大到全部文本，也不被扩大为任意再分发许可。仓库不分发手稿图像、照片、完整网页或原始页面缓存。双语摘要和中文别名由项目依据所列事实编辑整理，明确区别于来源原文和官方译文。

代表点取自[教堂 Wikidata 实体](https://www.wikidata.org/wiki/Q472082?oldid=2517889057)的固定版本与 P625 声明，结构化数据采用 [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing)。该点是所在教堂的公开参考位置，不是室内墓穴的测量坐标；来源数值精度不等于位置误差，`location_precision` 保持 `null`。现代来源国家和历史背景叠加均不证明历史政治归属。

`target_review.json` 保留原语料身份与字段校验、来源快照 SHA-256、坐标声明、范围和独立复核方法；`target_sites.json` 与 `target_manifest.json` 是可离线重建的固定派生文件。其余来源批次、许可证、原始字段、顺序和检索文本不变。
