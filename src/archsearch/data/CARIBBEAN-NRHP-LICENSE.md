# 波多黎各与美属维尔京群岛公共文化点位

本批从美国国家公园管理局公开名录核对波多黎各 5 处和美属维尔京群岛 2 处。冻结文件记录正式登记编号、点位来源、快照校验、公开访问范围和原始经纬度。[国家历史名录空间数据](https://www.nps.gov/subjects/nationalregister/data-downloads.htm)

两个历史堡垒保留国家公园管理局代表点。Fort Frederik 的两个登记编号指同一地点，使用主编号 `96001073`。三个灯塔分别采用美国海岸警卫队《2024 Light List, Volume III》中对应现存历史塔的原坐标，转换为十进制度。Punta Higüero 与 Cabo Rojo 仅核实可到达的外部区域。联邦机构发布的这些登记和坐标事实按美国公有领域使用。[美国海岸警卫队原表](https://navcen.uscg.gov/sites/default/files/pdf/lightLists/LightList_V3_2024.pdf)

Castillo Serrallés 保留经馆方导览位置对照的 Wikidata [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing) 坐标，Caguana 采用 ICOMOS／IAU 公开个案中对考古公园的代表坐标。馆方与地方主管机构的页面、个案描述及影像保留各自权利。新增点位采用断代未确定状态。
