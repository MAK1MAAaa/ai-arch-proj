# 卢旺达公共文化点位

本批收录卢旺达 4 处，由卢旺达文化遗产学院公布入场范围。鲁卡里王宫博物馆的代表点对应整片公开参观园区，保留较粗的来源精度。鲁韦塞罗馆舍原拟作王宫，启用前国王去世，现为基维吉拉博物馆的公开展览场所。历史阶段保留未知状态。[卢旺达文化遗产学院](https://www.rwandaheritage.gov.rw/en/museum-and-heritages-sites-management-division-1) · [博物馆参观安排](https://www.rwandaheritage.gov.rw/en/visit-national-museums)

坐标采用 Wikidata [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing) 的原始声明。布隆迪基特加馆址因修复期间的开放范围与候选点所属建筑尚待核验而暂缓。吉绍拉已有对应资料。[基特加博物馆修复项目](https://www.aliph-foundation.org/en/projects/rehabilitating-the-national-museum-of-gitega)
