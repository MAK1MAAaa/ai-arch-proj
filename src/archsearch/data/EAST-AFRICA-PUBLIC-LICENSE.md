# 坦桑尼亚与乌干达公共文化点位

本批核验坦桑尼亚 5 处及乌干达 8 处公共文化和考古地点。桑给巴尔的 Maruhubi 与 Mtoni 两处宫殿各有公开预约条目，代表点对应各自宫殿范围。Wamala 的到访以布干达王国公开的管理人导览为依据。[坦桑尼亚旅游机构](https://www.tanzaniatourism.com/) · [桑给巴尔公众预约目录](https://utaliismz.go.tz/sites) · [乌干达旅游局](https://exploreuganda.com/) · [布干达王陵访问说明](https://buganda.or.ug/royal-tombs/)
