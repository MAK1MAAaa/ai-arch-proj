# 毛里塔尼亚与马里公共文化点位

本批收录努瓦克肖特国家博物馆、巴马科马里国家博物馆及锡卡索的 Mamelon 历史丘 3 处。博物馆资料指向当局开放的原有场馆。Mamelon 代表点对应主管方列入公开导览的历史丘，保留来源坐标精度。开放情况、名称、公开范围与既有遗产记录的重叠检查逐条保存在冻结文件。断代阶段保留未知状态。

代表点均采用 Wikidata 固定修订提供的 WGS84 原始坐标，适用 CC0。当地主管方及场馆资料用于核对文化身份和公开范围，其短摘录保留来源权利。[Wikidata 许可](https://www.wikidata.org/wiki/Wikidata:Licensing)
