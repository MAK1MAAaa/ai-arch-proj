# 葡萄牙公共考古点位

本批收录 17 处具名考古遗址，覆盖罗马聚落、别墅、山堡与史前遗址。皮索恩斯别墅和埃什库拉尔洞穴采用主管方公布的预约方式，埃什库拉尔代表点为公开遗址参考位置。阿尔卡拉只涵盖博物馆公布的开放核心区域。历史阶段保留未知状态。[葡萄牙国家遗产票务](https://bilheteira.patrimoniocultural.gov.pt/) · [埃什库拉尔参观信息](https://www.cm-montemornovo.pt/locais/centro-interpretativo-da-gruta-do-escoural/) · [皮索恩斯参观信息](https://www.uevora.pt/en/service/Visiting-UEvora/pisoes-roman-villa2)
