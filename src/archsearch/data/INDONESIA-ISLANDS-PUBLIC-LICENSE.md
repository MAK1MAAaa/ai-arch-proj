# 印度尼西亚岛屿公共文化点位

本批加入 19 处公共文化地点，覆盖苏门答腊、苏拉威西、马鲁古和北马鲁古、加里曼丹、龙目及巴厘。参观范围见印尼国家旅游信息系统和各地主管机构记录。Leang-Leang 的点代表有公开解说的考古公园。Goa Gajah 是 Petanu 流域的独立遗址，坐标经核对位于世界遗产 1194 正式保护范围之外。新增点位的历史阶段保留未知状态。[国家旅游信息系统](https://sisparnas.kemenpar.go.id/) · [Leang-Leang 公园管理资料](https://kel-leangleang.maroskab.go.id/wisata) · [世界遗产 1194 正式地图](https://whc.unesco.org/en/list/1194/maps/)

所有采用的代表点均来自 Wikidata [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing) 具名坐标。国家地名库、地方政府公示、保护区地图和管理方资料用于核验位置、身份和开放范围。来源校验摘要保存在发布的冻结复核文件。
