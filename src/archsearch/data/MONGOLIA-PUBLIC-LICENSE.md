# 蒙古公共文化点位

本批收录 8 处有公共访客依据的历史地点，包括博克多汗冬宫、乔金喇嘛庙、甘丹寺公开参访区、扎纳巴扎尔美术馆旧建筑、曼殊寺公开遗迹区、庆宁寺、哈玛尔寺公开区域及宰桑纪念地。宰桑代表点对应纪念地公共区域，乌兰巴托市博物馆因现有原始坐标落在邻近街道而留待核验。庆宁寺属于世界遗产暂定名录。历史阶段保留未知状态。[乌兰巴托市旅游局官方地图](https://tourism.ub.gov.mn/wp-content/uploads/720x500_2024-last-1.pdf) · [博克多汗宫博物馆](https://bogdkhaanpalacemuseum.com/about/) · [庆宁寺暂定名录](https://whc.unesco.org/en/tentativelists/5947/)
