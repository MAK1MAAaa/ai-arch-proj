# 北大西洋公共文化点位

本批收录法罗群岛柯克丘伯的圣马格努斯大教堂遗址、格陵兰努克国家博物馆旧港 B-66 仓库，以及冰岛雷克雅未克旧长屋原址。法罗点位采用管理方开放的遗产参观范围。努克代表点采用历史仓库内的常设展所在建筑，购票入口另由运营者公布。雷克雅未克条目采用地下展示的考古原址及其地址，访客入口由市博物馆独立管理。断代阶段保留未知状态。[格陵兰国家博物馆](https://en.nka.gl/) · [雷克雅未克市博物馆](https://borgarsogusafn.is/en/the-settlement-exhibition)
