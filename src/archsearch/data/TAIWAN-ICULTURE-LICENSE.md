# 台湾 iCulture 公共古迹点位

署名为文化部 iCulture，2026 年取得的发布数据为「查詢單一類別文化設施資料」古蹟类及「查詢單一文化設施詳細資料」。批量与逐条接口均按 [政府资料开放授权条款第 1 版](https://data.gov.tw/license) 公开。 [类别目录](https://data.gov.tw/dataset/10046) · [详情目录](https://data.gov.tw/dataset/10043)

2026-11-28 从 1,063 条批量记录中选取 54 条。每条有原 `mainTypePk`、国定古迹标记、原名、来源县市、开放说明和唯一的代表经纬度。54 份逐条官方响应独立下载，并对身份、类别、开放字段、县市、经度和纬度逐项复核。清单保留各响应的原始字节校验值，随库分发的是必要字段和项目摘要。开放状态可能随机构公告变动。

剔除了经纬原字段超出适用范围的两条、开放证据不明确的场所及可能重复的对象。保留原登录日作为行政记录，历史阶段采用现有的断代未确定状态。`TW` 用于目录地理筛选。地图沿用发布者原有代表点，不由地址反查坐标。
