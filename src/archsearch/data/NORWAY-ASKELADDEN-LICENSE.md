# 挪威国家遗产登记公共文化点位

本批加入挪威 8 处公共文化地点。公众范围以 Forsvarsbygg 和指定场馆运营者公布的室外区域、展馆及导览为依据。季节、活动和馆内安排见相应管理方说明。新增点位的历史阶段保留未知状态。[Forsvarsbygg 公共遗产目录](https://www.forsvarsbygg.no/en/festningene/) · [Østfoldmuseene](https://ostfoldmuseene.no/)

代表点采用 Wikidata [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing) 具名坐标。挪威文化遗产局 **Riksantikvaren** 通过 Geonorge 提供的 Askeladden 遗产范围按 [NLOD 1.0](https://data.norge.no/nlod/en/1.0) 使用，用于逐条复核代表点与已登记的同名保护对象。语料保存核验引用和来源校验和。 [官方数据说明](https://register.geonorge.no/register/versjoner/produktark/riksantikvaren/kulturminner-lokaliteter-enkeltminner-og-sikringssoner)
