# 阿尔及利亚公共文化点位

本批收录特莱姆森 3 处、奥兰及君士坦丁各 1 处。迈什瓦尔记录考古原址复建的王宫与尚存城堡公开区域。西迪·布迈迪安清真寺及曼苏拉分别限于公开外部参观路线和露天遗址。君士坦丁的艾哈迈德贝伊宫记录原宫建筑内的公共博物馆。历史阶段保留未知状态。[特莱姆森旅游办公室](https://office-tourisme-tlemcen.dz/monuments.html) · [阿尔及利亚文化遗产地图](https://cartes.patrimoineculturelalgerien.org/fr/lieu/25-constantine/130)
