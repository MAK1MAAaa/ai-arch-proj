# 阿鲁巴和库拉索公共文化点位

本批收录阿鲁巴埃屈里家族原宅建筑群和布希里巴纳黄金冶炼厂遗存，以及库拉索萨沃内特历史主屋。埃屈里建筑群采用博物馆的公开原址，冶炼厂采用遗存外侧观览区域代表点。萨沃内特主屋采用运营者公开的博物馆范围，保护区内其他地点以主管方指定范围为准。萨沃内特所在的西库拉索种植园属于世界遗产预备名单。阿鲁巴和库拉索作为来源地区标签，荷兰王国的既有遗产资料保持来源标签。断代阶段保留未知状态。[萨沃内特运营者](https://www.christoffelpark.org/nl_NL/savonet-museum) · [预备名单](https://whc.unesco.org/en/tentativelists/5632/) · [联合国 M49 地区条目](https://unstats.un.org/unsd/methodology/m49/)

原宅与萨沃内特主屋使用 Wikidata 原始 WGS84 声明，适用 CC0。冶炼厂采用 GeoNames 10280574 原始 RDF 的 WGS84 公开点，署名 GeoNames，适用 CC BY 4.0。运营者和主管机构短摘录保留各自来源权利。[GeoNames 原始条目](https://sws.geonames.org/10280574/about.rdf) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [Wikidata 许可](https://www.wikidata.org/wiki/Wikidata:Licensing)
